# 年轻化自定义日程管家

微信原生小程序 · 本地存储 · 零后端 · 简约清新

## 功能说明

| 模块 | 功能 |
|------|------|
| 日常 | 待办列表、完成度统计（全部/待完成/已完成/完成率）、新增/完成/置顶/删除任务 |
| 日历 | 日/周/月三视图切换、日期导航、当日任务展示 |
| 计划 | 分类标签筛选（学习/工作/休闲）、置顶任务区、截止时间设置 |
| 随笔 | 备忘录自由记录、时间显示、字数统计 |
| 设置 | 浅色/深色双主题、6款预设壁纸、手机相册自定义背景、数据导出/清空 |

## 技术栈

- 微信原生框架（WXML / WXSS / JS）
- 本地持久化存储（wx.Storage）
- CSS 变量实现双主题切换
- 系统深色模式自动跟随

## 导入部署步骤

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开工具 → 导入项目 → 选择 `D:\young_plan_app` 目录
3. 填写 AppID（测试可用测试号）
4. 点击「编译」即可预览运行
5. 真机调试：点击「预览」→ 手机微信扫码

## 界面效果

- 圆角卡片布局 + 柔和渐变配色
- 任务新增/完成/删除过渡动效
- 全机型屏幕自适应（rpx 布局）
- 深色模式：导航栏/背景/卡片同步切换

## 目录结构

```
young_plan_app/
├── app.js / app.json / app.wxss    # 应用入口、全局配置、主题系统
├── project.config.json             # 微信开发者工具配置
├── utils/storage.js                # 本地存储封装（CRUD + 统计）
├── pages/
│   ├── index/                      # 日常首页
│   ├── calendar/                   # 日历视图
│   ├── plan/                       # 计划管理
│   ├── memo/                       # 随笔记录
│   └── settings/                   # 主题/背景设置
└── images/                         # 图标资源
```
